# Shobmilbe.com — Version 1
Basic modular e-commerce frontend.

## Upload
Upload all files/folders to the same GitHub repository where the current `index.html` lives.
Do not delete your existing index.html unless you want to replace it.

## Product data
Edit `data/products.json` to add products. Images can be placed in `assets/images/`.

## Next versions
Admin panel, database, real order processing, authentication, inventory, SEO controls, Google/Meta integrations and advanced product management can be added modularly.
