# সবমিলবে — অনলাইন শপ

Node.js দিয়ে বানানো ই-কমার্স ওয়েবসাইট। Vercel-এ চলে, ডাটা থাকে Neon (Postgres) ডাটাবেসে।

## যা আছে

- **দোকান:** হোমপেজ, ক্যাটাগরি, সার্চ, পণ্যের পেজ, কার্ট, চেকআউট (ক্যাশ অন ডেলিভারি), অর্ডার ট্র্যাকিং
- **Admin Panel (`/admin`):** অর্ডার দেখা ও অবস্থা বদলানো, পণ্য যোগ/এডিট (ছবিসহ), ক্যাটাগরি, ডেলিভারি চার্জ ও যোগাযোগের তথ্য

## প্রথমবার চালু করা

1. Vercel প্রজেক্টে Neon ডাটাবেস Connect করা থাকতে হবে (`DATABASE_URL`)।
2. সাইট খুললেই টেবিল আর নমুনা পণ্য নিজে থেকে তৈরি হয়ে যাবে।
3. `/admin`-এ গিয়ে Admin পাসওয়ার্ড তৈরি করুন। **এটা ডিপ্লয়ের পরপরই করবেন**, কারণ প্রথম যে পাসওয়ার্ড দেবে সেটাই সেভ হবে।

## ফোল্ডার

| ফোল্ডার / ফাইল | কী আছে |
| --- | --- |
| `api/index.js` | Vercel-এর এন্ট্রি পয়েন্ট, সব পেজ এখান দিয়ে যায় |
| `lib/app.js` | কোন লিংকে কোন পেজ দেখাবে |
| `lib/db.js` | ডাটাবেসের টেবিল আর কাজ (পণ্য, অর্ডার, সেটিংস) |
| `lib/pg.js` | Postgres-এর সাথে কথা বলার কোড (বাইরের কোনো প্যাকেজ লাগে না) |
| `lib/views/` | পেজগুলোর HTML |
| `public/` | CSS, JavaScript, ছবি |

## নিজের কম্পিউটারে চালানো (ডেভেলপারদের জন্য)

```
echo 'DATABASE_URL=postgres://...' > .env
npm start
```

তারপর http://localhost:3000 খুলুন।
